# شبیه‌سازهای ترمینال

[English guide](README.md)

دو دموی کنسولی بر پایهٔ تمرین‌های اولیهٔ Python. `terminal_demo.py` یک روایت تعاملی و زمان‌دارِ خیالی را پخش می‌کند. `phrase_demo.py` چند عبارت تصادفی از فهرست واژه‌های نمونهٔ مستقل نمایش می‌دهد. هر دو **شبیه‌سازی** هستند.

```bash
python terminal_demo.py
python phrase_demo.py --count 5
```

دموی ترمینال **اسکن شبکه، کشف آسیب‌پذیری، نفوذ یا استخراج فایل واقعی** انجام نمی‌دهد و از بازهٔ IP مخصوص مستندات استفاده می‌کند. برنامهٔ عبارت‌ها **استخراج رمزارز، ساخت عبارت کیف پول معتبر یا بررسی موجودی** انجام نمی‌دهد. واژه‌نامه‌های حجیم و فایل `pass.txt` اولیه اضافه نشده‌اند. Python 3 کافی است. مجوز MIT.
